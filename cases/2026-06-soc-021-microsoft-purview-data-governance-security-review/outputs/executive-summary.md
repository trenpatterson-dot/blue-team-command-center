# SOC-021 Executive Summary

A simulated Microsoft Purview security review identified elevated data governance risk across SharePoint, OneDrive, Teams, and Exchange.

The most important findings were broadly accessible payroll files, active external sharing links, missing sensitivity labels, incomplete Data Loss Prevention coverage, inconsistent retention, and a lack of documented recurring audit review.

Recommended priorities are to validate access with data owners, review external sharing, pilot sensitivity labels, extend DLP simulation across Microsoft 365, and establish recurring access and audit governance. Policy changes should be tested and approved before enforcement.

The evidence supports prioritized remediation and deeper authorized review. It does not establish malicious insider activity, data exfiltration, legal breach, regulatory noncompliance, or employee misconduct.

This is a documentation-first lab/case study using simulated evidence. It does not represent a production Purview deployment, tenant ownership, enterprise authority, legal/compliance authority, production SOC employment, or live customer or employee data access.
