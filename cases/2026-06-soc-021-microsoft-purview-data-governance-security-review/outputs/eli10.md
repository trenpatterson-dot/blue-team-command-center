# SOC-021 ELI10 Summary

Imagine a company has important employee and payroll files stored in several Microsoft 365 places.

Microsoft Purview can help find where sensitive information may exist, whether files have the right labels, and whether they are shared too widely. In this simulated case, some payroll files had broad access, some OneDrive files had external links, and several sensitive files had no label.

The security analyst identifies the risks and recommends safer sharing, clearer labels, better Data Loss Prevention coverage, and regular audit review.

The analyst does not decide legal requirements or accuse anyone of wrongdoing. Authorized data owners, privacy, legal, compliance, HR, and business leaders make those decisions.

This is a lab/case study using simulated evidence, not a live Microsoft 365 tenant or real employee data.
