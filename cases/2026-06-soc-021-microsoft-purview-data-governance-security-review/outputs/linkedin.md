# LinkedIn Draft

Completed SOC-021: Microsoft Purview Data Governance Security Review.

This lab/case study focused on reviewing simulated Microsoft 365 data risk across SharePoint, OneDrive, Teams, and Exchange.

Key areas reviewed:

- Sensitive information types
- Employee and payroll data exposure
- Overly broad SharePoint access
- External OneDrive sharing
- Missing sensitivity labels
- Data Loss Prevention coverage gaps
- Insider risk considerations
- Microsoft 365 audit logs
- Access governance and escalation criteria

The biggest takeaway: finding sensitive data is only the first step. Security teams also need consistent classification, least-privilege sharing, DLP coverage, audit visibility, and clearly assigned decision owners.

The analyst can document evidence and recommend action, but authorized privacy, legal, compliance, HR, business, and data owners retain final authority.

This was a simulated portfolio project, not production SOC activity, legal advice, or a live Microsoft Purview tenant review.
