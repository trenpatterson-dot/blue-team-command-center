# A Cybersecurity Lab Explained for 10-Year-Olds

A cybersecurity lab is like a detective's office, but instead of solving mysteries about missing cats or stolen cookies, we solve puzzles about computer problems. In this case, we looked at a special report called the "2026 06 Soc 016 Incident Report Executive Summary."

In this lab, we used a tool called PowerShell to help us investigate. We reviewed the incident summary, event timeline, and important notes about what happened. Unfortunately, some parts of the investigation are missing, like the command history and screenshots.

We found out that someone tried to sneak into our computer system using four different techniques: T1027, T1059.001, T1105, and T1204.002. These are like secret moves in a game of cybersecurity!

Why does this matter? Well, if someone can sneak into our computer system, they might be able to see or change important information. But because we're smart detectives, we caught them and can fix the problem before any real damage happens.
