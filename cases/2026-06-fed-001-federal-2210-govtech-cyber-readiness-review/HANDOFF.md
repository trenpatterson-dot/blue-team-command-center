## Goal

Create a recruiter-ready portfolio alignment case that explains how existing Blue Team Command Center cases support federal 2210 / GovTech / public sector cybersecurity analyst role language without overstating experience.

## Scenario

A cybersecurity graduate with IT support experience and a growing blue-team portfolio wants to understand which federal 2210 and GovTech cyber roles are realistic near-term targets. The analyst reviews public portfolio cases and maps them to work areas that appear in public sector cyber postings: incident response, identity and access management, vulnerability management, risk documentation, executive communication, security operations support, and governance concepts.

## Recommended Target Lanes

1. Information Technology Specialist (INFOSEC) roles that allow entry-level or early-career cybersecurity evidence.
2. IT Cybersecurity Specialist roles focused on monitoring, documentation, IAM, risk review, or vulnerability tracking.
3. Security Analyst / SOC Analyst roles using SIEM, Microsoft Sentinel, incident response, and documentation language.
4. IAM Analyst roles using Microsoft Entra ID, Conditional Access, MFA, least privilege, and Zero Trust language.
5. Vulnerability Management Analyst roles using prioritization, remediation planning, SLA, and risk communication language.
6. Security Risk Analyst / GRC Analyst roles where NIST, CIS Controls, documentation, executive summary, and risk register concepts matter.
7. GovTech Cybersecurity Analyst roles that value operational support, documentation, and cross-team communication.

## Avoid-for-Now Lanes

- Senior Offensive Cyber Operator
- Red Team Operator
- Exploit Developer
- Malware Reverse Engineer
- Senior Cyber Architect
- GS-13/14 technical lead roles
- Clearance-required roles if active clearance is mandatory
- Roles requiring 5-10+ years of production federal cyber experience

"My portfolio is not federal work experience. It is lab-based evidence that I understand the workflows common in public sector cyber analyst roles: alert triage, identity review, vulnerability prioritization, risk documentation, and clear handoff writing."

Avoid saying:

- "I worked federal cybersecurity cases."
- "I held clearance."
- "I managed government systems."
- "I performed official 2210 duties."
- "I remediated production vulnerabilities."
- "I owned compliance decisions."
