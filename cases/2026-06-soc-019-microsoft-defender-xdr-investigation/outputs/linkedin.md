# LinkedIn Draft

Completed SOC-019: Microsoft Defender XDR Investigation.

This case study focused on investigating suspicious PowerShell execution from an endpoint alert through final analyst disposition.

Key areas practiced:
- Microsoft Defender XDR
- Endpoint alert triage
- Process tree review
- PowerShell command analysis
- MITRE ATT&CK mapping
- Incident reporting

The biggest takeaway: PowerShell is powerful, but context determines whether it is normal admin activity or potential attacker behavior.

This was a lab/case study for portfolio development, not production SOC activity.
