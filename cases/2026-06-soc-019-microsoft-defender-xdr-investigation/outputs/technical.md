# SOC-019 Technical Summary

## Case
Microsoft Defender XDR Investigation

## Alert
Suspicious PowerShell Execution Detected

## Summary
This case reviews a simulated Defender XDR endpoint alert involving PowerShell execution from a workstation.

## Key Findings
- PowerShell execution was detected on a workstation.
- The parent process and command-line behavior required review.
- No confirmed evidence of payload download, persistence, or privilege escalation was identified in the initial scenario.
- The case demonstrates endpoint triage and analyst disposition workflow.

## Skills Demonstrated
- Defender XDR investigation
- Endpoint alert triage
- Process tree review
- PowerShell command analysis
- MITRE ATT&CK mapping
- Incident documentation
