# SOC-019 — Microsoft Defender XDR Investigation

## Case Type
Lab / case study

## Objective
Investigate a Microsoft Defender XDR endpoint alert involving suspicious PowerShell execution.

## Scenario
A workstation generated an alert after PowerShell launched with suspicious command-line behavior. The analyst must review process activity, device context, user context, and possible follow-on behavior to determine whether the activity is benign, malicious, or inconclusive.

## Skills Demonstrated
- Microsoft Defender XDR investigation workflow
- Endpoint alert triage
- Process tree review
- PowerShell command analysis
- Device timeline review
- MITRE ATT&CK mapping
- Incident reporting
- Human analyst decision-making

## Evidence Boundary
This is a lab/case study. It does not represent production SOC employment, enterprise authority, or access to real customer data.
