# SOC-020 ELI10 Summary

Imagine a security alarm goes off and an analyst has to copy the same details into several places before starting the real investigation.

Microsoft Logic Apps can act like a careful assistant. It can collect the alert name, user, computer, IP address, severity, and time. It can make a checklist, notify the analyst, and prepare a draft note.

The assistant does not decide whether the alert is safe or dangerous. A human analyst still checks the original evidence and decides whether to close the alert, escalate it, or request approved containment.

This project is a lab/case study using simulated evidence, not a live customer environment.
