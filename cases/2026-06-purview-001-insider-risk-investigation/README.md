# PURVIEW-001: Microsoft Purview Insider Risk Investigation

## Case Type

Lab-based portfolio investigation using simulated Microsoft Purview insider-risk evidence.

## Recruiter Snapshot

This case demonstrates how a SOC analyst can review an insider-risk alert without jumping to conclusions. The review considers sensitive data movement, DLP context, user activity, process evidence, and remediation boundaries.

This is a simulated review. It does not represent production SOC employment, live customer data access, or authority to discipline users or make legal determinations.

## Scenario

A simulated Microsoft Purview alert reports possible transfer of sensitive business information to personal cloud storage. The analyst reviews available evidence and determines whether the alert supports escalation.

## Final Determination

The simulated evidence did not confirm data exfiltration or malicious activity. The case remains useful as a portfolio example of careful evidence review, data-loss risk triage, and human approval boundaries.
