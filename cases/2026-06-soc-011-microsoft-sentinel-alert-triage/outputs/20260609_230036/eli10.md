# A Cybersecurity Lab Explanation for 10-Year-Olds

In this lab, we played detectives in a digital world! We worked on a special project called "2026 06 Soc 011 Microsoft Sentinel Alert Triage." This is like a case file where we use tools to find out if something suspicious happened.

Here's what we did:

1. **Reviewed the Alert Summary:** We looked at a special message that told us about some unusual activity happening on the computer network.

2. **Found the Affected User Account:** We identified which user account was involved in this strange activity.

3. **Investigated Failed Sign-Ins:** We checked if someone tried to log into the affected account multiple times from a suspicious source, like an unknown computer or device.

4. **Checked for Successful Logins:** We also looked to see if anyone managed to successfully log in after all those failed attempts.

This lab is important because it helps us learn how to protect our digital world from bad actors who might try to trick their way into our systems. By understanding these techniques, we can create stronger defenses and keep everyone's information safe!
