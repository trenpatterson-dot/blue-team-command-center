# Cybersecurity Lab: Powershell Suspicious Script Investigation

In this lab, we were investigating a suspicious PowerShell script. This isn't like playing video games or building Legos, but it's just as important because we're trying to protect computers from bad guys!

## What was done

1. **Reviewed the PowerShell alert summary**: This is like reading a report about what happened on a computer. It told us that something suspicious happened and gave us some clues about what it might be.

2. **Identified the affected host and user**: We found out which computer and user were involved in this event. Knowing who and where can help us understand what happened better.

3. **Reviewed suspicious PowerShell command-line activity**: We looked at the commands that were run using PowerShell, a tool used to automate tasks on Windows computers. Some of these commands seemed strange, so we needed to investigate further.

4. **Checked for download behavior and encoded or bypass-style arguments**: Sometimes bad guys use tricks to hide what they're doing. We looked for signs that the script was trying to download something or using special codes to avoid detection.

## What was found

We found evidence that a PowerShell script was running some suspicious commands. This could be a sign of a cyber attack, so it's important to investigate further and make sure the computer is safe.

## Why it matters

Cyber attacks can cause a lot of problems, like stealing sensitive information or making computers crash. By investigating these events, we can help keep our computers secure and protect against future attacks. This lab helped us practice our skills and learn more about how to find and stop cyber threats.
