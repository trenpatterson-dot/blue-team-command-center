# A Cybersecurity Lab for Finding Dormant Accounts

In this lab, we used a special tool called PowerShell to help us find accounts that haven't been used for a long time. This is important because these dormant accounts can be a security risk.

Here's what happened:

1. We started by looking at a list of accounts. Some of these accounts were still enabled, but they hadn't been used in a very long time.
2. We checked if these dormant accounts had any special privileges. This is important because accounts with high privileges can cause more damage if they are misused.
3. We also looked at some accounts that were meant for contractors or temporary workers. These accounts should be reviewed to make sure they are still needed and secure.
4. Finally, we found some accounts that required our attention. These accounts either needed to be validated by their owners, disabled, or had unnecessary privileges removed.

By doing this lab, we were able to find accounts that could potentially be a security risk. This helps keep our systems safe and secure.
