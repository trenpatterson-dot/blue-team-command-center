## Evidence Handling Rules

- Do not invent evidence.
- Do not add real usernames, emails, hostnames, IP addresses, domains, URLs, hashes, file paths, ticket IDs, tokens, passwords, or secrets.
- Do not execute malware.
- Do not run endpoint isolation, process termination, file deletion, quarantine, or blocking from this case folder.
- Do not add raw endpoint exports unless approved for local lab use.
- Keep private notes and raw artifacts out of public portfolio content.
- Review screenshots before sharing or committing them.
- Keep containment, endpoint isolation, process termination, file deletion/quarantine, account action, sensitive evidence collection, user contact, escalation, closure, publishing, and external communication behind human approval.
