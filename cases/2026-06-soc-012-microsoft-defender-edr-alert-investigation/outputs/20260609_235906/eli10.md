# A Cybersecurity Lab Explained for 10-Year-Olds

In this cybersecurity lab, we played a game called phishing. Phishing is like pretending to be someone you're not to trick people online. But in our lab, we didn't play with real people, we used computers instead!

The lab was set up on a computer that wasn't connected to the internet (standalone). This means it couldn't reach out to other computers or websites. We did this so no one would get hurt.

We used a tool called PowerShell to help us investigate. PowerShell is like a magic box that can do lots of things on a computer, like running commands and looking at files.

In the lab, we saw some strange things happening on a computer (endpoint). For example, there was a suspicious PowerShell command that was run. We also looked at who was using the computer and what they were doing before the strange event happened. This is called a command history.

We used something called Advanced Hunting to help us find more information. Advanced Hunting is like a detective's notebook, but for computers. It helps us ask questions about the computer and get answers.

By looking at all this information, we were able to figure out that someone was trying to trick the user into giving them their password or other important information. This is bad because it can let people access the user's account and do things they shouldn't be able to do.

To make sure nothing bad happened, we took some steps to stop the problem. We looked at what the strange PowerShell command did and how it connected to other commands on the computer. Then we stopped it from doing any more harm. This is called containment and remediation.

This lab was important because it helped us practice finding and stopping bad things on computers. It's like training for a superhero who protects people online!
