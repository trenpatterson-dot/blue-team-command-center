# SOC-018 — Microsoft Sentinel Alert Investigation

## Case Type
Lab / case study

## Objective
Investigate a suspicious Microsoft Sentinel sign-in alert from initial triage through final incident report.

## Scenario
A user account shows multiple failed sign-in attempts followed by a successful sign-in from an unusual source IP/location. The analyst must determine whether the activity is malicious, benign, or inconclusive.

## Skills Demonstrated
- Microsoft Sentinel alert triage
- Sign-in log review
- Entity investigation
- Timeline creation
- MITRE ATT&CK mapping
- Severity assessment
- Incident reporting
- Human analyst decision-making

## Evidence Boundary
This is a lab/case study. It does not represent production SOC employment, enterprise authority, or access to real customer data.
