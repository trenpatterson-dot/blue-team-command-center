# SOC-018 Technical Summary

## Case
Microsoft Sentinel Alert Investigation

## Alert
Suspicious User Sign-In Activity

## Summary
This case reviews a simulated Microsoft Sentinel alert involving repeated failed sign-in attempts followed by a successful authentication event.

## Key Findings
- Multiple failed authentication attempts were observed.
- A successful authentication occurred after the failed attempts.
- MFA was completed successfully.
- No evidence of privilege escalation or malicious follow-on activity was identified.
- The alert was closed as benign activity with monitoring recommendations.

## Skills Demonstrated
- Alert triage
- Sign-in log analysis
- Timeline development
- MITRE ATT&CK mapping
- Severity assessment
- Incident documentation
