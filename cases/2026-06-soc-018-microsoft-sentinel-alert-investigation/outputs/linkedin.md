# LinkedIn Draft

Completed SOC-018: Microsoft Sentinel Alert Investigation.

This case study focused on investigating suspicious sign-in activity from initial alert triage through final disposition.

Key areas practiced:
- Microsoft Sentinel alert triage
- Authentication log review
- Timeline creation
- MITRE ATT&CK mapping
- Severity assessment
- Incident reporting

The biggest takeaway: a suspicious login pattern needs evidence-based investigation before calling it a compromise.

This was a lab/case study for portfolio development, not production SOC activity.
