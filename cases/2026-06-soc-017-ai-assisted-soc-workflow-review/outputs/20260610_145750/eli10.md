# A Cybersecurity Lab Explained for 10-Year-Olds

In this project, called the **2026 06 Soc 017 Ai Assisted Soc Workflow Review**, we played detective in a cybersecurity lab. This lab was like a special room where we investigate when something suspicious happens on computers.

In our lab, we used a tool called PowerShell to help us look around. We reviewed a security alert summary and checked out some correlated events (events that happened at the same time). Then, we used a smart helper to write an initial summary about what might have happened. Lastly, we made a list of all the evidence we found during our investigation.

This work is important because it helps us find out if there were any bad guys trying to cause trouble on our computers. By doing this, we can keep our computers safe and secure! However, there are still some missing pieces in our investigation, like command history and screenshots. We'll need to find those soon so we can be sure we've found everything.

In the end, we hope to write a report about what happened and decide if anything needs to be done to fix it. This is all part of being a cybersecurity analyst!
