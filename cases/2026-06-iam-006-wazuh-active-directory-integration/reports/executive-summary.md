# Executive Summary — IAM-006

This case demonstrates how Windows identity and security events can be integrated into Wazuh for centralized SOC monitoring. By reviewing account and authentication activity inside a SIEM, analysts can detect suspicious IAM behavior faster and reduce reliance on manual endpoint checks.

The focus of this case is visibility: confirming that Windows security events are available in Wazuh and can be filtered for failed logons, account changes, password reset activity, and privileged access indicators.
