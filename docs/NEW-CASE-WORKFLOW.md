\# New Case Workflow



This guide explains how to start a new investigation case in Blue Team Command Center.



The goal is to keep every case organized, portable, and safe to review later.



\## Before Starting



Confirm which mode you are working in:



\- Personal Lab Mode

\- Company-Safe Template Mode

\- Sanitized Export Mode



If this is a company investigation, keep real evidence inside approved company systems unless policy allows otherwise.
