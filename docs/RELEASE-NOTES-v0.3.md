# Release Notes: v0.3

Tag: `v0.3`

## Summary

v0.3 expands Blue Team Command Center with two completed SOC workflow chains while preserving the project's Markdown-first, portable, analyst-led, and human-approval-gated operating model.

## Completed Workflows

- Completed malware alert triage workflow.
- Completed account compromise workflow.
- Existing failed login, phishing, and suspicious PowerShell workflows remain present.

## Added or Updated Artifacts

- Added or updated malware alert triage checklist, playbook, and practice case.
- Added or updated account compromise triage checklist, playbook, and practice case.
- Added or updated related analyst summary, executive summary, lessons learned, indicators, findings, timeline, and handoff Markdown artifacts for the completed practice cases.

## Safety and Boundary Notes

- Public/private boundary is preserved.
- No private evidence was added.
- No screenshots, logs, exports, packet captures, binaries, malware samples, or restricted evidence were added.
- Human approval gates are preserved for containment, blocking, deletion, account changes, host isolation, ticket updates, user notification, and other operational actions.

## Planned Follow-Up Items

- Vulnerability finding workflow remains planned.
- Endpoint alert triage workflow remains planned.
