# Copy Case Template



Use this guide to create a new investigation case from the reusable case template.



## Purpose



The `cases/_template/` folder provides a clean starting structure for every SOC-style investigation.



It includes:



- Case overview

- Handoff notes

- Timeline

- Indicators

- Findings

- Analyst summary

- Executive summary

- Lessons learned

- Evidence placeholder folders



## Step 1: Choose a Safe Case Name



Use a clear date-based name.



Recommended format:



```text

YYYY-MM-DD-short-case-name
```
