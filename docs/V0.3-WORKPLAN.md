# v0.3 Workplan

## Goal

Expand Blue Team Command Center with more SOC investigation workflows and stronger analyst-review structure.

Blue Team Command Center remains a portable Markdown-first SOC and Blue Team analyst workbench. v0.3 should build on the stable v0.2.1 release without weakening the public/private boundary, human approval safeguards, or review-only posture for operational actions.

## Current Stable Baseline

v0.2.1 already includes:

- Failed login workflow
- Phishing workflow
- Suspicious PowerShell workflow
- Sanitized screenshot workflow
- Reusable case template
- Practice cases
- Playbooks
- Checklists
- Analyst reports
- Executive reports
- Lessons learned reports
- Human approval safeguards
- Markdown rendering cleanup

## Recommended v0.3 Workflows

Planned v0.3 expansion items:

- [ ] Malware alert triage checklist
- [ ] Malware alert practice case
- [ ] Account compromise checklist
- [ ] Account compromise practice case
- [ ] Vulnerability finding workflow
- [ ] Endpoint alert triage workflow

## Priority Order

Recommended implementation order:

1. Malware alert triage
2. Account compromise
3. Vulnerability finding
4. Endpoint alert triage

## Success Criteria

v0.3 should be complete when:

- At least two new workflows are completed.
- Each new workflow has a checklist.
- Each related playbook links to its checklist.
- Each completed workflow has a practice case.
- Practice cases include analyst summary, executive summary, lessons learned, indicators, findings, timeline, and handoff.
- Public/private boundary rules are still followed.
- No operational actions are automated or implied.

## Safety Rules

- No secrets.
- No real company evidence.
- No screenshots unless sanitized and reviewed.
- No destructive action.
- Human approval required for operational actions.

## Suggested First Build

Start v0.3 with the malware alert triage chain:

- `checklists/malware-alert-triage-checklist.md`
- Update `playbooks/malware-alert-triage.md`
- Create `cases/2026-05-26-malware-alert-practice-case`

Do not automate containment, blocking, deletion, account changes, host isolation, ticket updates, or user notification. Keep the workflow analyst-led, review-only, and safe for a public Markdown-first SOC workbench.
