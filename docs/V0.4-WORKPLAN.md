# v0.4 Workplan

## Goal

Expand Blue Team Command Center with vulnerability finding and endpoint alert triage workflows.

Blue Team Command Center remains a portable Markdown-first SOC and Blue Team analyst workbench. v0.4 should build on the stable v0.3.1 release without weakening the public/private boundary, human approval safeguards, or review-only posture for operational actions.

## Current Stable Baseline

v0.3.1 already includes:

- Failed login workflow
- Phishing workflow
- Suspicious PowerShell workflow
- Malware alert triage workflow
- Account compromise workflow
- Reusable case template
- Playbooks
- Checklists
- Practice cases
- Analyst reports
- Executive reports
- Lessons learned reports
- Release notes
- Public/private evidence boundary
- Human approval safeguards

## Recommended v0.4 Workflows

v0.4 planned expansion items:

- [ ] Vulnerability finding checklist
- [ ] Vulnerability finding playbook update
- [ ] Vulnerability finding practice case
- [ ] Endpoint alert triage checklist
- [ ] Endpoint alert triage playbook update
- [ ] Endpoint alert triage practice case

## Priority Order

Recommended implementation order:

1. Vulnerability finding workflow
2. Endpoint alert triage workflow

## Success Criteria

v0.4 should be complete when:

- [ ] Vulnerability finding workflow is complete.
- [ ] Endpoint alert triage workflow is complete.
- [ ] Each workflow has a checklist.
- [ ] Each related playbook links to its checklist.
- [ ] Each completed workflow has a practice case.
- [ ] Practice cases include analyst summary, executive summary, lessons learned, indicators, findings, timeline, and handoff.
- [ ] Public/private boundary rules are followed.
- [ ] No operational actions are automated or implied.

## Safety Rules

- No secrets.
- No real company evidence.
- No screenshots unless sanitized and reviewed.
- No destructive action.
- No live scanning unless explicitly approved.
- No exploitation instructions.
- Human approval required for operational actions.

## Suggested First Build

Start v0.4 with the vulnerability finding workflow:

- `checklists/vulnerability-finding-checklist.md`
- Update `playbooks/vulnerability-finding.md`
- Create `cases/2026-05-27-vulnerability-finding-practice-case`

Do not automate scanning, exploitation, containment, blocking, deletion, account changes, host isolation, ticket updates, or user notification. Keep the workflow analyst-led, review-only, and safe for a public Markdown-first SOC workbench.
