# NIST Cybersecurity Framework Mapping

Use this file to map case work to NIST CSF functions at a high level.

## Identify

- Asset context.
- Business owner identification.
- Risk and impact understanding.

## Protect

- Access control recommendations.
- Security awareness recommendations.
- Baseline hardening and configuration recommendations.

## Detect

- Alert review.
- Detection logic.
- Monitoring gaps.
- Threat hunting findings.

## Respond

- Triage.
- Escalation.
- Incident coordination.
- Containment recommendations requiring approval.

## Recover

- Lessons learned.
- Service restoration notes.
- Recovery validation recommendations.

## Use Note

Do not claim NIST CSF compliance from a single case note. Use this mapping only to explain relevance.
