# MITRE ATT&CK Mapping

Use this file to describe observed adversary behavior. Map only behavior that is supported by evidence.

## Common Mapping Areas

- Initial Access.
- Execution.
- Persistence.
- Privilege Escalation.
- Defense Evasion.
- Credential Access.
- Discovery.
- Lateral Movement.
- Collection.
- Command and Control.
- Exfiltration.
- Impact.

## Mapping Rules

- Map behavior, not guesses.
- Include the evidence reference when permitted.
- If evidence is weak, say "possible" or "suspected."
- Do not over-map normal administrative activity.
- Do not claim a specific actor without approved intelligence.

## Example Language

- "The observed encoded PowerShell command may relate to Execution and Defense Evasion if confirmed malicious."
- "Repeated failed logins across multiple accounts may relate to Credential Access behavior if the pattern is confirmed as password spraying."
