# CIS Controls Mapping

Use this file to connect findings and recommendations to CIS Controls at a practical level.

## Common SOC-Relevant Areas

- Inventory and control of enterprise assets.
- Inventory and control of software assets.
- Data protection.
- Secure configuration of assets and software.
- Account management.
- Access control management.
- Continuous vulnerability management.
- Audit log management.
- Email and web browser protections.
- Malware defenses.
- Security awareness and skills training.
- Incident response management.

## Use Guidance

- Tie the mapping to a specific recommendation or finding.
- Avoid claiming full implementation from a single activity.
- Note whether the mapping is about detection, response, hardening, or governance.

## Example Language

- "This recommendation supports account management and access control management objectives."
- "This finding relates to audit log management because authentication evidence was incomplete."
