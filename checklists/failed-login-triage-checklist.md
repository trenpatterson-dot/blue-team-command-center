# Failed Login Triage Checklist



Use this checklist when reviewing repeated failed login activity.



The goal is to separate normal user error from suspicious authentication behavior while keeping the investigation evidence-based.



## 1. Case Basics



- [ ] Case or ticket created

- [ ] Alert name documented

- [ ] Alert source documented

- [ ] Analyst name documented

- [ ] Date and time documented

- [ ] Timezone documented

- [ ] Severity documented

- [ ] Related playbook linked
